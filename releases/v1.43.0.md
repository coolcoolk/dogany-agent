## 목적 (purpose)

앵커: **조용한 실패 소탕** -- 구조적으로 열릴 수 없던 게이트(비공개 레포 push),
항상 초록이던 검사(legacy-grace no-op lint / 0건 인덱싱 exit 0), 소리 없이 내용물을
떨구던 배달(발행 KEEP 누락 / fastpath 버튼 / session-inbox poison-pill / 한글 바이트
절단)을 전부 **증명하거나, 시끄럽게 실패하거나, 폐기**하도록 만든다. 여기에 1.42.0
번호로 준비됐던 3단 배포 링 첫 컷(시험 채널 태그 + promote 4조건 판정 + 통합 갱신
루프)을 운반한다.

문제: 이 판의 결함들은 공통적으로 "우리 쪽 계기판은 전부 초록인데 실제로는 아무것도
안 되고 있는" 클래스다. 비공개 레포 push 게이트는 오너 신원이 본문인 레포에
공개경계 스윕을 돌려 영원히 닫혀 있었고(미푸시 수백 커밋의 진짜 원인, DGN-1058),
발행 KEEP 열거는 신규 의존을 12시간 내 2회 조용히 떨궜으며(DGN-1038), /authsync는
회전된 refresh token을 구형으로 되돌려 estate 전체 인증을 매일 죽였다(DGN-1050).
launchd/cron의 C 로케일에서 한글이 바이트로 잘려 푸시가 통째 소실되고(DGN-1059),
깨진 파일은 브리지가 20초마다 영원히 재시도했다(session-inbox poison-pill).

그리고 대화 중 동생이 조용히 전멸했다 -- `/stop`이 아니라 **형님이 말만 걸어도**
발동하는 자동 인터럽트가 세션 내 에이전트를 무조건 쓸어버렸다(DGN-991/1016).

Anchor: DGN-1058 + DGN-1038 + DGN-991 (riders: DGN-1059, DGN-1050, DGN-1049,
DGN-1052, DGN-1055, DGN-1021 4th-path, DGN-1018 §5-B, DGN-407 전파,
session-inbox 격리, installer 메뉴 어휘, health-trainer publish;
운반: DGN-1031/1044/1046/1032/960 = 1.42.0-dev분)

## Highlights

0. **백그라운드 동생 재배치 (DGN-991, 실증 착지).** 원격 interrupt는 턴 abort와
   **무관하게** 레지스트리 순회 킬러를 무조건 호출한다 -- `scope` 필드는 원격
   프로토콜 스키마에 **존재 자체가 없고**, 주입해도 무효임을 실측했다. 즉 "안 죽는
   중단 신호"는 없다. 방어층 대신 **재배치**: `dispatch-detached.sh`가 워커를
   `setsid`로 자기 세션에 띄워 킬러가 도는 레지스트리 **밖**에 둔다.
   3종 비교 실측 -- 세션 내 Task 동생은 interrupt에 즉사, 배경 셸은 interrupt는
   넘기고 disconnect에 사망, **detached 워커만 양축 생존 + 완주(120/120)**.
   의존 2종(`usage-gate.sh`, `lib/ledger-update.sh`)이 템플릿에 부재라 함께 환류
   (피호출자 없는 호출자를 만들지 않는다). 신규 민트 첫 스폰이 렛저 부재로 죽는
   결함 1건을 발견해 부트스트랩으로 봉합. 기존 파일 수정 0 = 회귀 표면 없음,
   셀프테스트 32/32. **스케줄 미동봉**(스크립트는 항상, 등록은 옵트인).
   근거: 형제 인스턴스 7일 동생 사망 14건 중 **9건이 자동 인터럽트**(`/stop` 0건).

1. **비공개 레포 push 게이트 해소 (DGN-1058).** 신규 스코프 기계 0줄 -- 기존
   DGN-808 owner-backup 면제 마커가 실제로 스윕을 축소(cat 1,6,7,8만 강제)하고,
   축소 사실은 **매 push마다 RESULT 라인에 출력**된다(clean full과 clean reduced가
   같아 보일 수 없다). fail-open(root)/fail-closed(template)로 몰래 갈라져 있던
   pre-push 훅 2벌을 byte-identical 1벌로 통합, missing-sweep 정책은 레포 내용
   (AGENT.md/USER.md/memories 존재 = PII 레포 = fail-closed)에서 런타임 판정.
   secret-sweep.sh는 update.sh 3k5로 인스턴스 동기 채널에 편입(민팅 시점에 얼어
   있던 3주 묵은 스윕 실측). 픽스처는 경로 허용목록 대신 **형태 자기선언**
   (TEST-ONLY- 접두사) + AWS 문서 예제 키 인용 면제(제거-후-재검사 방식).

2. **발행 의존성 폐포 게이트 E2/E2b (DGN-1038).** KEEP 스크립트가 참조하는
   레포 파일이 KEEP 밖이면 발행 차단(dry-run/execute 양쪽 hard, --force 없음).
   scripts/pack/lib/은 glob KEEP(`scripts/pack/lib/**`)으로 항목 누락을 구조적으로
   불가능하게, 역방향(E2b)은 그 디렉터리의 미참조 파일 발행을 차단해 dev 전용
   모듈의 공개 유출을 막는다(extract_section.py는 scripts/lib/로 재배치).
   scan/refs/unresolved/violations 카운트 매 실행 출력 -- 0건과 미실행이 같아
   보이지 않는다.

3. **UTF-8 로케일 환류 (DGN-1059).** 템플릿 push.sh/self-update.sh가 절단 전에
   실 UTF-8 로케일을 탐지(en_US.UTF-8 -> C.UTF-8 순 charmap 검증)해 export,
   `head -c`(바이트) -> `cut -c`(문자) 교체. UTF-8 로케일이 아예 없으면 침묵
   대신 WARN. 메탈 라이브에 고여 있던 수정(5ec4f95)의 캐노니컬 환류 -- 미환류
   시 다음 업데이트가 덮어 회귀 확정이던 건.

4. **session-inbox UTF-8 poison-pill 격리 (bridge).** 디코딩 실패 파일을
   `.corrupt`로 1회 격리 + ERROR 1건 -- 기존에는 같은 파일을 20초마다 영원히
   재시도하며 뒤에 정렬된 파일 전부를 막았다(실사고: 동일 에러 52건+).

5. **fastpath 4번째 [[OPTIONS]] 경로 배선 (DGN-1021 rider).** 도메인 fastpath
   push가 캐노니컬 인식기(has_options_marker) 미배선으로 force_options=False
   고정 -- 표+마커 동반 본문에서 표만 가고 버튼 0개. 나머지 3경로와 같은
   인식기로 계산해 배선(신규 탐지기 0). OSS 업스트림은 fastpath 자체가 부재라
   백포트 대상 없음(UPSTREAM.md 기록).

6. **/authsync 폐기 (DGN-1050).** file->keychain 무조건 덮어쓰기가 CLI 런타임
   회전 후 구형 refresh token을 재주입 -> 서버측 token-family revoke -> estate
   전면 인증 사망(일 단위 반복)의 근인. token-sync.sh는 읽기 전용 검사기로 전환
   (sync 서브커맨드 hard-fail, keychain 쓰기 0), DIVERGED는 에러가 아니라 설계상
   정상 상태로 보고(exit 0). 명령은 메뉴에서 제거, 숨김 스텁이 폐기 안내만 회신
   (catch-all 경유 SDK 세션 유입 차단). 유일한 자격증명 writer = CLI
   (`claude auth login`).

7. **행위팩 설치 프로파일 + devkit 계약 채택 (DGN-1018 §5-B, DGN-1049).**
   > 정정(2026-08-27, DGN-945 §5): 이 항목 제목의 "devkit"은 dev 행위팩(kind=pack,
   > id `dev`)의 당시 오지칭이다. devkit은 크루 공유 킷 제품 이름으로 예약(미구축).
   > 배포 당시 문구는 기록으로 유지한다.
   kind=pack + contract_version 팩이 실제 계약 설치 경로를 탄다: 킷 전용 스텝
   (db-init/migrate/mirror/units) 클래스 게이트 off, 서비스 표면은
   service_namespace 키. dev 팩 1.2.0이 첫 실채택(kind=pack, contract_version=1,
   requires_framework, D-D 서명) -- legacy-grace no-op가 초록으로 읽히던 공허한
   판정 폐기. payload는 계약 형태(payload/service/dev/)로 재배치.

8. **compat-lint C5 SQLite 우회 2건 봉쇄 (DGN-1049 rider).** 대소문자(DATA.DB)와
   메인 파일 없는 WAL 사이드카(*.db-wal/-shm/-journal)가 clean 통과하던 갭을
   소문자화 basename + 사이드카 포함 glob(`*.sqlite*` 포함)으로 봉쇄.

9. **공개 인스톨러 팩 메뉴 소생 + menu_visible (DGN-1049 SS3).** 메뉴 필터가
   폐기된 상태 어휘('official')를 보고 있어 published 팩 전원이 제외 -> 메뉴가
   조용히 비어 있었다. 어휘 정렬(published), kit 행은 철자가 아니라 kind로 제외,
   빌더측 팩은 menu_visible=false로 메뉴만 숨김(id 프리셋 설치는 유지 --
   hidden != forbidden). health-trainer는 D-D 반대서명 짝으로 draft->published.

10. **devkit ticket-hygiene 정직화 (DGN-1052, DGN-1055).** 접두사 하드가정을
    TICKET_FILE_GLOB 노브(env -> agent.conf -> 접두사 유도 폴백)로 교체, 0건
    인덱싱은 exit 0 위장 대신 시끄러운 실패. 빈 id가 dedup에 삼켜져 티켓이

    처방은 인스턴스 규약 우선으로 교체(형님 결정 2026-08-23).
    > 정정(2026-08-27, DGN-945 §5): 항목 7과 동일 -- 이 항목 제목의 "devkit"도
    > dev 행위팩(ticket-hygiene 스크립트의 소속 팩) 오지칭이다.

11. **티켓 접두사 규약 템플릿 전파 (DGN-407).** 접두사는 인스턴스 고유(DGN- =
