## Highlights

### 1. 팩이 독립 제품이 된다

킷·스킬 묶음이 프레임워크와 분리된 버전 라인을 갖는다. 설치 규약(`packs/CONTRACT.md`),
페이로드 표면 계약, 팩 좌표 해석, 설치기 참조/복사 규약이 함께 착지했다.

**두 팩이 같은 스킬을 배송하는 경우를 기계가 잡는다** (DGN-1143). 이전에는 설치 순서가
승자를 정했고 아무도 그걸 보지 않았다. 배송원 목록은 손으로 적지 않고 **배송기 앵커에서
파생**되므로, 새 표면이 생겨도 선언을 잊어서 빠지는 일이 없다.

### 2. 3단 배포 링

`dev` → `staging` → `stable`. `promote.sh --check` 가 승격 관문이고,
dev 태그 컷 경로와 핫픽스 레인이 신설됐다. 이전에는 stable 한 종류만 있었다.

### 3. 종결 보장 -- 침묵 금지

비동기·지연 의무는 **완료 또는 실패로 끝난다**. 종결 원장과 sweep 이 배선됐고,
구동은 서로를 감시하지 않는 두 다리(주기잡 / 위임 경로)로 덮는다.

착지 과정에서 이 축이 정의하는 실패형이 실제로 발견됐다 -- 위임 스크립트가
**존재하지 않는 원장 스크립트를 호출하고 있었고, 61건 검사 스위트는 전부 초록이었다.**

### 4. 에이전트 규약 문서 구조 이행 (파괴적)

`PROFILE.md` / `USER.md` / `DISCIPLINE.md` 가 `identity/` · `rules/` 로 이동하고,
벤더 계약이 `vendors/` 로 분리된다. 로더 허브(`AGENTS.md`)가 신설되고
**인스턴스가 직접 쓴 내용은 `*.custom.*` 규약으로 보존**된다.

이행은 상태 기반이라 중간에 끊겨도 재실행하면 수렴하고, 되돌리는 절차(`docs/ROLLBACK.md` 8a2)가
단독으로 완결된다.

### 5. 공개 경계 청소

공개 미러에서 개발/릴리스 기계류를 적출하고, 오너 개인정보가 하드코딩된 경로를 제거했다.
발행 KEEP 목록의 구멍과 역방향 레거시 선적을 닫았다.

### 6. 선언과 실물의 상시 대조

**선언(원장·카탈로그·매니페스트)과 실물(설치된 것)이 어긋나면 매일 잡는다.**
이 감사가 없던 동안 세 종류의 문제가 같은 뿌리에서 자라고 있었다.
