## 목적 (purpose)

이번 마이너는 두 갈래를 함께 싣는다 -- 선택지 버튼 출력 통합(DGN-790, user-facing)과
lifekit 크루 병합 엔진 도입(DGN-791, 내부 인프라).

- 버튼(DGN-790): [[OPTIONS]] 렌더링의 폭·잘림 처리를 일관된 출력 계약으로 통합.
  유저가 체감하는 유일한 변화.
- 크루 병합 엔진(DGN-791 C안): 두 에이전트 인스턴스의 lifekit DB를 하나의 크루 DB로
  1회 병합하는 재사용 canonical primitive(scripts/crew-merge/). 결정론적 id-remap +
  자연키 dedup + 원자 promote + 우산 카운트게이트. 3라운드 적대 그릴 수렴(실데이터 손실
  2건 적발·해소), test 38/38 GREEN.

## 경계 (scope boundary)

- 이번 릴리스는 도구만 코어에 싣는다. 실제 lifekit 데이터 병합(cutover)은 별도
  오너 freeze 게이트에서 실행하며 release에는 포함되지 않는다.
- lifekit 코어 무결합(C안): 엔진은 DB/schema/migrate 경로를 전부 CLI 주입으로 받는
  standalone이라 database/lifekit.py 등 코어 파일에 정적 결합이 0이다.
- lifekit v19 통합본의 아그·워그 인스턴스-로컬 착지는 Skull 레인(코어 릴리스와 별개).
- lifekit 독립 팩 정식화(DGN-681)는 다음 목적버전에서 설계+그릴 후 진행.
