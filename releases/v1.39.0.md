## 목적 (purpose)

앵커: 결정론 인터랙션 층 -- 로깅/드릴다운 인터랙션을 "모델 내레이션 메시지
스트림"에서 브릿지 결정론 콜백으로 옮긴다. 버튼을 누를 때마다 모델이 한 턴 돌던
것(새 메시지 도배 / 딜레이 / 표 유실)을 제거하고, 진행 표시 정책을 에이전트
클래스별로 정비한다.

문제: 세트 로깅 같은 반복 인터랙션이 매 선택마다 모델 한 턴 -> 새 메시지 도배 ·
딜레이 · 표 유실 · 순서 깨짐으로 이어졌다(운동 세션 붕괴 사고). 진행 표시도
클래스 구분 없이 전 에이전트 fold가 기본이라, 생활 에이전트의 실시간 코칭 스텝이
접힌 인용으로 뭉개졌다.

Anchor: DGN-939

## Highlights

1. 인플레이스 콜백 엔진. 한 메시지의 인라인 키보드에서 버튼을 누르면 그 메시지가
   제자리 갱신(다음 단계 요구)된다. 봇파더식 «뒤로 계층 네비. **새 메시지 0 ·
   모델 턴 0 · 딜레이 0.** 기존 2단계 드릴다운(reps->RIR)을 N단계로 일반화하고,
   최종 선택 시 기록 + 표 갱신까지 무모델턴 결정론으로 처리.

2. 진행 표시 정책. 개발 에이전트 = 실시간 스트리밍 후 턴 완료 시 접힌 기록으로
   정리 + 최종답 별도 버블(live-then-fold). 생활/도메인 에이전트 = 실시간만
   (접힘 없음). 미설정 기본값 = 도메인 실시간. 개발 인스턴스는 클래스 설정으로
   접힘 유지.

3. 접이식 인용 렌더. 본문엔 결과만, 심층/부가 설명(쉬는시간 계산 근거, 강도
   설명 등)은 펼쳐보는 확장형 인용에 담는다. 코칭/팁은 접지 않고 본문 유지.

4. 캡션 /queue 합치기. 사진·문서 캡션 맨 앞의 /queue도 텍스트 /queue와 동일하게
   진행 중인 턴을 끊지 않고 다음 턴으로 대기-병합.

5. arm 계약 + 배포 노브. 드릴다운 플로우(키보드 값·텍스트·검증·발화 커맨드·
   접이식 인용)를 선언 파일로 지정하면 그 위에서 도메인 플로우가 배선된다.
   보안 불변: 경계 가드 · 스텝별 화이트리스트 · no-shell 실행 · 단발 소비.
