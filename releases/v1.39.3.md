## 목적 (purpose)

앵커: **인터랙션 표면 결정론화** -- 버튼/핀이 "경로와 소유자에 따라 있다 없다 하는" 비결정성 제거.

문제: 같은 세트 기록도 fast-path로 처리되면 버튼이 안 뜨고 모델 턴으로 처리되면 뜨는 등, 인터랙션
표면(버튼/핀)이 처리 경로에 따라 비일관했다. 핀 표면은 프레임워크와 도메인이 한 파일을 이중소유해
프레임워크 빈쓰기가 도메인 핀을 삭제했고, 스트리밍 출력은 타이밍(스트리밍 중 vs 종료 후)에 따라
마크다운이 깨졌다 멀쩡했다 했다. v1.39.3은 이 세 결정론 결핍을 한 앵커로 묶어 해소하고, 2.0 항해
전 남은 안정성 라이더(CLI 신선도, watchdog 복구 갭, authsync 경로)를 함께 접어 낸다.

Anchor: DGN-968 (refs DGN-966, DGN-967, DGN-969)

## Highlights

1. 공유 아티팩트 렌더 경로 (DGN-966). 모델턴 / fast-path / 프로액티브 push 세 발송 경로가 이제
   하나의 렌더 테일(`bridge/artifacts.py` + `_send_content_artifacts`)을 공유한다. fast-path가
   `[[IDRILL:...]]` 마커를 조용히 삭제만 하던 결함을 제거해 세 경로 모두 동일한 키보드를 렌더한다.
   `push.sh`는 기존 단일 버튼(DGN-835) 제약을 넘어 다중 버튼 행 + 그리드 + 봇파더식 drilldown을
   한 번의 발송으로 지원한다(`--button` 시그니처는 무변경). 라이더: N-step arm 확인 문구의 `{i}`
   토큰이 첫 캡처값에 고정되던 결함을 전체 캡처 리스트 렌더로 교정. 신규 user-facing 문구
   `external_file_omitted_noninteractive`(ko/en, dec-094 UX 게이트 통과) -- 비대화형 레일(push/
   fast-path)에서 PROJECT_ROOT 밖 파일을 보류할 때 로그+무버튼 알림으로 안내한다(기존 모델턴 레일의
   대화형 확인 버튼은 무변경).

2. 핀 표면 섹션 소유 (DGN-967). `dashboard.md` 한 파일을 프레임워크 작업대 보드와 도메인 카드(예:
   운동 종목표)가 함께 쓰던 구조에서, 프레임워크의 "표시할 게 없으면 빈 문자열"이 도메인 섹션까지
   지워버리던 결함을 고쳤다. 이제 각 소유자는 자기 섹션만 갱신하고, 한쪽이 비어도 다른 쪽 콘텐츠는
   보존된다. 도메인 측의 롤백 우회(가드 스크립트)를 걷어낼 수 있는 상태.

3. 스트리밍 디마크 (DGN-969). 스트리밍 중인 답변 말풍선은 지금까지 마크다운 서식이 전혀 적용되지
   않는 평문이었다 -- `**bold**` 등이 텍스트 그대로 노출되다가, 턴이 끝나야 정상 렌더로 바뀌었다
   (긴 답변은 그 최종 전환마저 실패해 지우고 다시 그리는 폴백까지 탔다). 완결된 마크다운 쌍은 스트리밍
   중에도 마커를 벗겨 평문으로 보여주고(생짜 `**` 비노출), 최종 결과는 기존과 바이트 동일하게 렌더한다.
   청크 분할로 마커가 반토막 나는 경우까지 처리. 형님 UX 게이트 통과 항목(락 전 실렌더 before/after 확인).

4. 핀 서식 렌더 (DGN-974). 고정 핀 메시지는 지금까지 `parse_mode` 없이 발송돼 **평문 전용**이었다 --
   핀에 코드블록/굵게/인라인코드를 쓸 수 없었고, 도메인 카드(운동 종목표)를 코드블록 표로 실을 수
   없었다. 이제 대화 경로와 동일한 변환기 조합을 태워 HTML로 발송한다. 핵심은 폴백이다: 변환이
   실패하거나 텔레그램이 파싱을 거부하면(`can't parse entities`만 좁게 매칭) 즉시 평문으로
   재시도한다 -- 티켓 제목에 `<`나 `&`가 섞여도 **핀이 사라지거나 갱신을 멈추지 않는다.**
   "message is not modified" 같은 무관한 오류는 폴백이 삼키지 않고 기존 경로로 그대로 흐른다.
   DGN-967 섹션 소유와 짝을 이룬다 -- 소유자가 자기 섹션에 임의 서식 콘텐츠를 쓸 수 있어야
   섹션 소유가 의미를 갖는다.

## 라이더 (안정성)

- DGN-963 -- start.sh PATH 표준화: `$HOME/.local/bin`(자가업데이트되는 네이티브 CLI 설치 경로)가
  Homebrew/`/usr/local/bin`보다 먼저 해소되도록 정렬. DGN-961 stale-CLI 재발 경로(죽은 소유
  npm-global 사본이 우선 잡히던 것)를 근원에서 차단.
- DGN-964 -- watchdog 마커 자가치유 + plist 결정성: 서비스 마커가 한 번도 기록되지 않은 설치에서
  DGN-888 자동복구 백스톱이 조용히 비활성 상태로 남던 갭을 정상 heartbeat 주기에서 자가 backfill로
  메운다. 동일 라벨 후보가 여러 plist에 걸칠 때의 선택도 결정론화(모호하면 WARN, identity 일치 우선).
- DGN-929 -- /authsync 스킬 경로 해석: 워크스페이스(`PROJECT_ROOT/.claude/skills`) 우선 + HOME
  폴백으로 `/skills` 커맨드와 동일한 이중탐색을 쓰도록 교정. 표준 인스턴스 레이아웃에서 상시
  "스크립트 없음" 오탐이 나던 결함 해소.
- DGN-965 -- install.sh plist 선택 결정론화: `install_launchd`가 `bridge/*.plist` 첫 글롭
  매치(알파벳 운)에 의존하던 것을 DGN-964와 **동일 패턴**으로 교체 -- identity 기반 Label 일치
  우선, 무매치 시 정렬-첫 후보, 0건이면 조용한 추측 대신 loud no-op + 수동 명령 안내.
  `*.watchdog.plist`도 후보에서 제외(기존엔 "newbridge" &lt; "watchdog" 알파벳 순서에 의존).
  레거시 plist 잔재가 있는 디렉토리에서만 발현하던 오선택이라 신규 민팅은 무영향.
