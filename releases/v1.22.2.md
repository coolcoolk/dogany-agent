# Release notes -- v1.22.2 (2026-08-02)

Type: PATCH (bridge + routines + baseline docs; no schema change; no migration
required for consumers).

## Summary

Recovers the reserved bundle that v1.22.1 shipped empty, plus one Ag-reported
P1. Four tickets (DGN-685/686/687/688) were reserved for v1.22.1 but were still
`wip` when the cadence rule (DGN-690) alone took the v1.22.1 tag -- the reserved
work silently dropped out. A new release gate (DGN-691, gate 5b) now blocks
tagging whenever any ticket reserved for the target version is not `done`, so
this class of silent drop cannot recur. This release lands that recovered bundle
plus DGN-692 (an Ag upstream report that had no relay path to Metal).

## What shipped (per ticket)

- DGN-685 -- Update approval now carries through to restart in one step. A
  successful `self-update.sh` triggers restart directly (interactive =
  `--trigger user` immediate; autonomous/cron via CLAUDECODE-env gate =
  `--trigger auto`, idle-guarded). No separate restart step or menu.
- DGN-686 -- Register guard v2, drop-only. The bridge now only drops a pure
  English block (0 Korean, 80+ chars); fragment masking was retired (leak is
  blocked upstream by leader summarization -- see DGN-694). Emergency kill-switch
  (`BRIDGE_REGISTER_GUARD`, default on) restored. is_error handling reworked:
  transient failures (overloaded/529/timeout/5xx) auto-retry once, then surface a
  typed notice with a [retry] action; auth/token expiry prompts re-login without
  retry.
- DGN-687 -- Update-flow user-facing copy: availability nudge, install-complete,
  restart-complete, and a resume line -- rendered with Telegram expandable
  blockquote release notes. Branding "framework" -> "Dogany"; user-facing term
  "restart".
- DGN-688 -- `push.sh --html`: proactive push (reminders/briefings/completion
  notices) can now use code blocks, quotes, and expandable folds (parse_mode=HTML,
  matching the bridge formatting allowlist), with a plain-text fallback on HTTP 400.
- DGN-692 -- `push.sh` no longer leaks `send_file::` marker lines as raw text in
  the outbound Telegram message (headless push is text-only; marker lines are
  stripped before transmission).

## Notes / rollout

- First-generation lag: this rollout run itself executes under the OLD
  `self-update.sh`, so the auto-restart wiring (DGN-685) takes effect only from
  the NEXT update. The fleet needs one manual restart this time -- do not expect
  auto-restart on this specific update.
- Companion items tracked but NOT in this canonical release: DGN-691 (gate 5b)
  lives in the metal operator's `release.sh` (not a canonical-shipped file);
  DGN-694 (leader output discipline) is a follow-up design ticket.
