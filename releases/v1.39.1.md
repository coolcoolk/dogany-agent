## 목적 (purpose)

패치: v1.39.0 결정론 인터랙션 층이 라이브에서 낸 회귀 3종 수리.

문제: DGN-930 토폴로지가 interim 내레이션과 최종답을 같은 스트리밍 핸들러
draft로 합치면서, 결정-턴 finalize(draft 삭제 / HTML no-op skip / overflow
scrub)가 interim+final glue 위에서 동작 -> (1) OPTIONS 버튼 파손, (2) raw
HTML 태그 노출. fold 모드에서는 fold+구분자+최종답이 한 버블 예산을 넘으면
compose가 fold를 통째로 떨어뜨려 (3) 내레이션이 모든 표면에서 유실됐다.

Anchor: DGN-947

## Highlights

1. inline seal (회귀 1+2 수리). 스트리밍 핸들러가 inline 터미널 경계에서
   interim 버블을 영구형으로 봉인(seal_segment)하고 draft 목록을 비운다 --
   핸들러를 latch하지 않으므로 최종답은 새 버블을 열고 자체 finalize를
   그대로 탄다. 버튼/HTML 회귀가 원천에서 사라진다.

2. fold budget-drop rescue (회귀 3 수리). 예산 초과로 fold가 떨어질 때
   살아남은 내레이션을 자체 버블(grown-path 최종형, 자체 예산)로 구출해
   최종답 위에 배치. fold 부재 원인 3종(budget rescue / lossless echo /
   teardown race)이 로그에서 분리돼 관측 가능.

3. 업데이트 통지 렌더 복원 (DGN-846). DGN-718 blockquote 레이아웃 복원 +
   streamed finalize의 raw-tag leak 수리 (contains_telegram_html 게이트).

4. idrill followup_cmd (rider, DGN-939 item2, 스컬 handoff). arm 파일의
   선택적 followup_cmd: 터미널 cmd/cmd_skip2가 exit 0일 때만 발화되는 후속
   argv. 동일 보안 불변(list-form subprocess / no shell / 절대경로 argv[0] /
   15s timeout); stdout은 새 인라인 메시지로 포스트(edit 아님). 필드 부재 =
   기존과 byte-identical.

5. grill hardening. fold rescue 전송 실패는 ERROR로 기록(허위 "rescued"
   성공 로그 제거), background 턴의 budget-drop은 손실로 기록(허위
   "lossless" 제거), argv[0] 절대경로가 계약 문서만이 아니라 코드에서 강제.
