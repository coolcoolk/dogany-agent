Stable release. Conversations and work in progress now continue more reliably
across delayed replies, interruptions, usage limits, and updates. See
CHANGELOG.md.

The agent keeps notification replies attached to the notice they answer, and
delivers the completed portion of a response if generation stops partway
through.

Current kit facts take precedence over older conversation memories, newer
memories win when records conflict, and plans with dates in the past are
identified as past.

Messages waiting behind a usage limit resume when the limit resets. After an
update, work resumes from choices that were already confirmed.

New installs include agent-browser by default. Its browser download is about
700 MB on first installation; macOS installs also include the screen-control
tool.

Card buttons acknowledge a tap immediately, mark the tapped option, and lock
the card while the pick is saved. The update progress bubble always reaches its
final frame, an empty rewritten answer no longer replaces the answer already
written, and the Korean /큐 command queues a message like /queue.
