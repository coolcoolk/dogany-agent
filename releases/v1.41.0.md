## 목적 (purpose)

앵커: **팩 의존 계약 + 논킷(agentpack) 페이로드 표면 계약** -- v1.40.0이 팩 게이트의
단일-킷 가정을 걷어냈다면, v1.41.0은 그 위에 "팩이 킷을 요구한다"는 의존 선언
(requires_kit)과 "킷이 아닌 팩은 무엇을 실을 수 있는가"라는 표면 계약(kind=pack
allowlist)을 시공한다. 게이트 전반부(compat-lint)와 후반부(pack_install) 양쪽이
같은 판정표를 독립 구현으로 들고, 교차 테스트가 드리프트를 감시한다.

문제: 팩 명세서에 의존을 선언할 자리도, 선언을 검사할 게이트도 없었다 -- 킷이 없는
인스턴스에 킷 의존 팩이 설치되는 것을 막는 기계가 부재했다(DGN-681 S4b). 논킷 팩은
kind 어휘조차 검증되지 않아 킷 전용 짐(database/ mirror/)을 밀수할 수 있었다
(DGN-1018). DOGANY_PACKS 장부 쓰기는 비원자적이라 동시 설치가 장부를 깨뜨릴 수
있었다(TK-13 U1). 라이더로, 라벨형 [[OPTIONS: a | b]] 마커가 세 곳의 수제 substring
인식기에 걸려 소리 없이 죽던 결함(DGN-1021 -- 워그 1.40.0 버튼 미출력 회귀 DGN-1019의
근인)을 캐노니컬 인식기 단일화 + fail-loud 승격으로 봉쇄한다.

Anchor: DGN-681 S4b-1 + DGN-1018 (TK-13 U1; riders DGN-1021, DGN-681 followup#2
catalog fix)

## Highlights

1. **requires_kit 의존 선언 -- 게이트 전반부 (DGN-681 S4b-1).** compat-lint C-KITDEP
   네임드 슬롯 신설: requires_kit 형식 검증(비-object / 키셋 불일치 / 킷 문법 /
   예약어 / 자기의존 / 레인지 문법 / kind=kit의 선언 = FAIL; 부재 = SKIP). 형식만
   본다 -- 충족 판정은 설치기 측. provides_kit 문법(_kit_token_ok)과 semver 레인지
   파서 재사용.

2. **requires_kit 충족 게이트 -- 게이트 후반부 (DGN-681 S4b-1).** pack_install
   설치시점(pre-payload-copy) 게이트: C-KITDEP 형식 판정의 의도적 독립 복제
   (DGN-1002 락스텝 선례) + DOGANY_PACKS 대상 충족 검사. 전 경로 fail-closed,
   WARN 레인 없음. Warg형 lifekit@1.2.0 vs '>=1.1.0 <2.0.0' = PASS 실측.

3. **agentpack 페이로드 표면 계약 (DGN-1018).** C-KIND 슬롯: kind는 정확히 kit|pack,
   그 외 FAIL+ABORT. KIT_NAME lifekit 기본값을 kind=kit로 스코프 축소; kind=pack의
   provides_kit 선언 = FAIL. C4 허용표를 클래스별 분기: pack은
   service/<service_namespace>/ + knowledge/ + skills-bundle + routines/bundle +
   config만, database/ + mirror/는 킷 전용 FAIL(ZERO-MIGRATION 기계화).
   contract_version=1 유지, 전부 additive, legacy-grace 무접촉.

4. **DOGANY_PACKS 원자적 upsert (TK-13 U1).** flock 직렬화 read-modify-write +
   same-dir tmp/fsync/os.replace 단일 프리미티브로 기존 비원자 쓰기 2개소 공동 수리.
   락 타임아웃 = loud FAIL, conf 무접촉. 단일-작성자 바이트 동일.

5. **verdict-identical 교차 테스트 (DGN-681 S4b-RATIFIED).** C-KITDEP(형식) <->
   pack_install(형식 복제분)을 같은 입력으로 실구동해 FAIL<->BLOCK / PASS<->PASS /
   SKIP<->SKIP 매핑을 고정 -- 의도적 이중화의 드리프트 알람.

6. **라벨형 [[OPTIONS]] 마커 침묵사 봉쇄 (DGN-1021, 라이더).** sdk_bridge 3개소의
   수제 `OPTIONS_MARKER in content` substring 인식기가 라벨형을 몰라
   has_options=False -> 버튼 블록 전체(내장 fail-loud 포함)가 통째 스킵되던 결함.
   전 지점을 캐노니컬 라인 인식기(has_options_marker)로 단일화, fail-loud를 게이트
   바깥으로 승격(마커가 게이트 꺼진 채 렌더 좌석에 도달하면 WARN), substring 인식기
   재발을 AST 가드로 차단. 메탈 인스턴스 검증분(a6acc00e)의 캐노니컬 back-land --
   워그 1.40.0 버튼 미출력 회귀(DGN-1019)의 근인 수리.

7. **카탈로그 좌표 정정 (DGN-681 followup#2, 라이더).** health-trainer 행의 이중
   좌표 드리프트 수리: package_dir을 실제 팩 레포(sibling checkout)로, pack_version
   중복 제거(팩 레포 매니페스트가 정본).
