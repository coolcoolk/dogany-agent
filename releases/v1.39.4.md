## 목적 (purpose)

앵커: **인터랙션 dead-end 제거** -- 시스템이 다음 행동을 이미 알고 있으면서 유저에게 그리로 가는
경로를 주지 않던 표면들.

문제: 세 자리에서 같은 결함이 났다. (1) 선택지를 목록으로 제시했는데 버튼이 렌더되지 않아 유저가
글자만 보고 답을 직접 타이핑해야 했다. (2) `/authsync`가 자격증명 동기화에 성공하면 재시작이
**필요하다는 것을 알면서** 재시작 경로를 주지 않고 "권장합니다"로 끝냈다. (3) `/stop`은 그 턴이
띄운 백그라운드 작업까지 함께 죽이면서 그 사실을 알리지 않아, 유저는 작업이 조용히 사라진 것을
나중에야 알았다. 셋 다 "시스템은 아는데 유저는 모른다" 형태의 dead-end다. v1.39.4는 이 셋을 한
앵커로 묶어 닫고, 벤더 트리 테스트 carry 결손 라이더를 함께 접어 낸다.

Anchor: DGN-994 (refs DGN-992, DGN-991, DGN-990, DGN-979)

## Highlights

1. **[[OPTIONS]] 라벨 마커 버튼 (DGN-992).** 선택지 목록이 버튼으로 승격되지 않고 평문으로
   증발하던 경로를 닫았다. 라벨 소스가 3계층으로 정리되고, 마커 뒤에 오는 bare 후행 라인도
   버튼 라벨로 수용된다. 과폭 라벨은 DGN-881 번호 핸들로 폴백. `bridge.md` 계약 문서도 3계층
   라벨 소스 기준으로 갱신.

2. **`/authsync` 재시작 CTA (DGN-994).** 동기화 성공 분기에 **한정하여** 재시작 버튼 1개가
   붙는다. MATCH(이미 일치) / NOT-APPLICABLE(비-macOS) / ERROR / SCRIPT_MISSING / SYNC_FAILED
   분기는 버튼 없음 -- 테스트로 고정. 탭하면 확인 단계 없이 `self_restart.sh --trigger user`로
   즉발한다(오너가 누른 버튼 = 명시적 재시작 명령). 리플레이 방어 3중: 키보드 선제 제거 +
   20분 stale gate + 120초 비고착 래치. 신규 유저 대면 문구는 라벨 1쌍(ko "재시작" / en
   "Restart")뿐이고, 실패 경로는 기존 `AUTHSYNC_ERROR`를 재사용한다.

3. **어휘 교정 -- "재기동" 퇴출 (DGN-990).** `/authsync` 성공 문구가 "봇 재기동을 권장합니다"
   에서 "봇을 **재시작**해야 합니다"로 바뀐다. "재기동"은 내부 운영어이고 유저 대면 표준은
   "재시작"이다. 동시에 약한 서술("권장")을 필요조건으로 정정했다 -- 새 자격증명은 재시작해야
   실제로 반영된다.

4. **`/stop`의 정직한 안내 (DGN-991, 과도기).** 실측으로 확정: 소프트 인터럽트 1회가 그 턴의
   서브에이전트를 **즉시** 죽인다(두 번째 `/stop`이 아니다). 그에 맞춰 기존 예고 문구를 폐기하고,
   첫 `/stop` 성공 응답에 결과를 지금 말하는 문구를 붙였다 -- 백그라운드도 함께 중단됨 + 이어가는
   방법(새 메시지) + 두 번째 `/stop`의 실제 의미(세션 프로세스 강제 종료). 강제 종료 결과 문구도
   "세션과 대화는 그대로"라는 거짓 주장을 걷어냈다.
   **이것은 과도기 표기다.** 요구사항은 소실 방지 자체이며, 별도 프로세스 재배치가 본해소다
   (DGN-991 후속). 재배치 착지 릴리스에서 이 문구는 반드시 재검토된다.

5. **벤더 테스트 carry 결손 보수 (DGN-979, 라이더).** DGN-920/922 carry가 `bot.py`만 벤더 트리로
   옮기고 테스트는 두고 가서 `test_dgn902_btw_command.py`가 frozen 상태였다. 라이브본을 단방향
   fast-forward. TEST-ONLY -- 런타임 파일 무변경, 핀 무이동. 이 보수로 기존 실패 baseline이
   7건에서 5건으로 줄었다.

## 인수된 한계

- `/authsync` 재시작 탭 직후 ~ 재시작 완료 통지 사이(약 30-60초) 중간 안내 없음. 버튼 소멸이
  즉시 피드백이고 완료 push가 종결 신호다.
- 키보드 제거 edit가 실패하면 버튼이 남아 재시작 후 20분 내 재탭 시 재시작이 1회 더 걸릴 수 있다.
  재시작은 안전·가역 연산이라 수용.
- `--resume-intent` 미배선: 브릿지는 세션 in-flight 상태를 모른다(= DGN-706 "no in-flight" 선언).
