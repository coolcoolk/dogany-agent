## Purpose

브릿지 견고화 -- 코어/브릿지 출력 계약 phase-1 + 렌더층 전면 재벤더 + 버전 스큐(렌더층 동결) 방지.

Self-update가 브릿지 렌더 파일을 갱신하지 않아 코어와 렌더층 사이 버전 스큐가 쌓이고
인스턴스가 HTML raw 노출 증상을 보이는 근본 원인을 제거한다. 동시에 브릿지 출력 계약
phase-1(미지마커 컨테인먼트 + fold/link_preview 어휘), OSS 브릿지 전면 재벤더(24커밋 델타,
DGN-582 폴드 배선 포함), 버튼 라벨 가중 폭 트림, 업데이트 알림 한글 상세 fold, release.sh
jargon 게이트, 인용 접기 dedup, 공고화 크론 usage 침묵 처리, 공개 미러 스냅샷 태깅을 묶는다.

## Changes

### DGN-757 -- self-update 브릿지 렌더층 동결 픽스

근본 원인(실측): DGN-625 init 시점에 `bridge/` 파일을 `.dogany-bridge.sha` 매니페스트 없이
시드한다. 첫 번째 `update.sh` 실행이 해당 파일을 class-5로 분류하면 DGN-677 adopt-provisional이
STALE 온디스크 시드를 보존한다; 두 번째 실행은 class-2-provisional을 CONFLICT로 격상시켜 명시적
`--bridge-accept` 없이는 갱신이 차단된다. 결과: 렌더층이 init 시점에 동결되고 코어는 계속
전진 -- 미인식 마커 raw 노출 증상(스컬 실증 사례: formatting.py 296줄에 동결, 코어 v1.26.1).

Fix(Option B): `bridge_vendor_ancestor()`가 매니페스트 미등록 파일의 git blob id를 프레임워크
저장소 `agents/.template/bridge/` 경로의 전체 이력과 대조해 "순정 벤더 조상" 여부를 증명한다.
증명 성공 시 현행 벤더 버전으로 자동 착지(백업 선행); 증명 실패(수동 편집 파일) 시 기존
adopt-provisional/CONFLICT 동작 유지. `.git` 미도달 환경에서는 안전 강등으로 기존 동작 유지.
Class-5(첫 실행, 동결 형성 전)와 class-2-provisional(기존 동결 플릿, 운영자 액션 없이 자동 복구)
양쪽에 배선한다.

스코프: `--all`로 출하(commit + branch 이력 전체 탐색, 테스트 144/144 그린). Tag-only 전환은
픽스처 재작업이 필요한 선택적 후속으로 추적.

구조 권고(루트 릴로케이션): DGN-625 git-home init과 `mint.sh`가 `bridge/` 파일을 시드하는
모든 경로에서 `.dogany-bridge.sha` 매니페스트도 함께 시드하면 class-5 부트스트랩 클래스 자체가
소멸한다. 조상 증명은 기존 플릿 복구 안전망으로 남는다.

### DGN-719 -- 브릿지 출력 계약 phase-1

코어/브릿지 사이에 채널 중립 마커 계약을 긋는 작업의 첫 번째 페이즈. 네 가지 산출물:

- **a2 미지마커 컨테인먼트(핵심 런타임 방어)**: `contain_unknown_markers()`가 `word::`/`[[WORD]]`
  형태의 미인식 마커를 안전 리터럴(zero-width space 삽입)로 강등하고 로그에 기록한다. Raw 릴레이
  금지. `markdown_to_telegram_html` 단일 초크포인트에 배선해 스트림/비스트림/chat/fold 전 경로를
  커버한다. 매치 정밀화: `::` 뒤 EOL/공백 필수 → URL/문장 중 오탐 0.
- **a3 fold typed-block**: `compose_fold_block()`/`render_fold_block()` -- summary를 필수 구조 필드로
  갖는 typed intent block. DGN-619 `>!` 경로로 바이트 동일 렌더.
- **a4 `link_preview::`**: `RECOGNIZED_COLON_MARKERS`에 편입(a2가 삼키지 않음).
- **a1 CONTRACT_VERSION -- 현재 DORMANT**: `CONTRACT_VERSION=1` 상수와 `check_contract_skew()`
  함수가 코드에 존재하나, 버전 stamp를 방출하는 producer도 live skew 체크를 수행하는 consumer도
  없다(bot.py 미참조). 런타임 스큐 방어는 전적으로 a2 컨테인먼트가 수행하며, a1은 phase-2(RULES-retrain
  이후 코어가 마커를 학습한 뒤) 활성화될 API 표면이다. Parity grill(SOUND, FATAL 0) 결과를 반영한
  정직화 처리(dec-108).

재벤더: OSS 브랜치 `dgn719-revendor-v127` @ ce3b597, canonical `88e4b87`. Parity guard가 phase-0
출력을 바이트 동일로 핀.

### DGN-710 -- 인용 접기 중복 dedup (compose 폴백)

짧은 턴에서 최종 답변 첫 문단이 접힌 진행 기록과 본문에 동시에 노출되는 버그 수정. 근본 원인:
`_finalize_result`의 final-vs-interim dedup이 `fold_msg_id is not None`(grown-bubble 경로)에만
적용되고, `fold_msg_id is None`인 compose 폴백 경로는 dedup 없이 그대로 prepend. 수정: compose
폴백을 grown-bubble 경로와 대칭으로 -- final이 interim에 완전 포함 시 fold 미부착, 부분 겹침 시
`_dedup_final_against_interim` 트림 후 prepend. DGN-699 락된 dedup 철학(option 1)의 누락 경로
보강이며 설계 변경 아님. DGN-721 재벤더에 포함되어 착지.
