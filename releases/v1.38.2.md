## 목적 (purpose)

앵커: 사용량 게이트를 상황에 맞게 켜고 끌 수 있게 -- 특히 7일 창 락아웃이
사용자 직접 세션까지 하드 차단해 오히려 승인 왕복으로 토큰을 낭비하던 문제 해소.

게이트의 본래 목적은 "사용량을 인지하지 못하는 자동 수행/팬아웃"이 5h/7d 공용
헤드룸을 태우는 걸 막는 것이다. 그런데 owner가 직접 몰고 있는 라이브 세션까지
7d 임계에서 하드 차단하면, owner가 곧 승인 권한임에도 block -> 비용설명 -> 승인
-> 센티넬 touch -> 재시도 왕복이 강제돼 오히려 토큰을 낭비한다. v1.38.2는 두
스위치로 이를 분리한다.

Anchor: DGN-925

## Highlights

1. `USAGE_GATE` 마스터 스위치 (DGN-925). `off`면 게이트 훅 전체가 no-op
   pass-through(완전 침묵) -- 킬 스위치. 기본 `on`(unset 동일).

2. `USAGE_GATE_7D` 7d 차단 범위 (DGN-925).
   - `full`(기본) -> 7d가 모든 세션 차단(기존 동작 그대로).
   - `auto-only` -> 7d는 **자동/크론 세션에만** 적용, owner 직접 라이브 세션은
     7d 면제(5h는 유지 + 비차단 번레이트 힌트는 계속 발화해 인지 유지).

3. 세션 구분 신호. 라이브 브릿지 세션은 `PROJECT_ROOT`(bridge/sdk_bridge.py)를
   물고 훅까지 상속; 헤드리스 자동 러너(autonomous-loop.sh / metal-shift.sh는
   launchd에서 `env -u CLAUDECODE claude -p`, PATH+HOME만)는 안 뭄. `DOGANY_SESSION=`
   명시 override 우선. Fail-safe: 불명 -> 자동 취급(7d 유지), 자동 팬아웃이
   실수로 뚫리는 방향은 원천 차단.

env(USAGE_GATE / USAGE_GATE_7D / DOGANY_SESSION)가 agent.conf보다 우선. 5h 창은
모든 세션에 항상 적용. DGN-835 relief/ledger/경량에디터 면제/센티넬 계층 전부 승계
(회귀 0). 기본값 unset이면 pre-change 동작과 동일 -- 일반 인스턴스 무영향.
