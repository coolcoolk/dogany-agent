## 목적 (purpose)

앵커: 브릿지/출력 계약 계층 정리(bridge.md 2층 분리 + L0 응답 골격 정식화) +
스트리밍 fold 기본값 변경으로 도메인 에이전트의 진행 나레이션 표시 기본화.
/kill 완전 제거 전파 + ready 빌드분(DGN-816/DGN-822/DGN-788) 탑재.

- 왜: (1) 출력 계약이 telegram.md 단일 파일에 혼재되어 범용 브릿지 규칙과 텔레그램
  렌더 특화 규칙이 구분되지 않았다 -- bridge.md 신설로 계약 계층을 명확히 한다.
  (2) INTERIM_MODE 미설정 인스턴스가 진행 나레이션을 suppressed(무음)로 방치했다 --
  기본값을 fold로 변경하여 가시성을 확보한다. (DGN-681 계열)
  (3) /kill은 /stop의 하드폴백 완성(DGN-581) 이후 불요해졌다 -- 완전 제거로 커맨드
  표면을 단순화한다.
  (4) DGN-816/822/788 ready 픽스 3건: 메시지 손상/포맷 누출/HTML 누출이 확인된
  회귀 결함이었다 -- 이 릴리스에 탑재한다.

## Highlights

1. 도메인 에이전트(워그 등)가 작업하는 동안 진행 나레이션을 접힌 인용 블록으로
   기본 표시한다. 기존 "말없이 혼자 작업" 동작이 근본적으로 해소된다.
   INTERIM_MODE 미설정 인스턴스의 기본값 suppress -> fold 변경. STREAM_INTERIM=true
   인라인 세팅은 inline 그대로 유지(하위호환). (dgn825-interim-fold-default, aac6d5f)

2. /kill 커맨드가 전 에이전트에서 완전히 사라진다. /stop 소프트 인터럽트가
   하드 폴백까지 처리하므로 별도 커맨드가 불요해졌다. canonical .template + OSS
   claude-code-telegram + 라이브 3축 전파 대상. (dgn825-kill-removal, cdd7201)

3. 출력 계약이 두 층으로 정리된다. 범용 브릿지 계약(bridge.md)과 텔레그램 렌더
   특화(telegram.md)가 분리되어 계층이 명확해진다. L0 응답 골격(결론/근거/결정 3칸)이
   AGENT.md workflow 정식 문구로 착지한다.
   canonical 착지: 재귀 import 실증 게이트 통과 후 예정(doctrine note 1 참조).
   (dgn825-bridge-md-l0-carryin, eda4538)

4. 메시지가 잘리는 풋터 스트리퍼 과삭제 버그가 수정됐다. _FOOTER_BLOCK_RE를
   라인시작(MULTILINE) + 메시지끝 앵커로 타이트닝 -- 본문 중간 [라이브]/[결정대기]
   리터럴이 잘리던 회귀 수정. 21케이스 green. (dgn816-footer-strip, c2e53e1)

5. push.sh 발송 경로에 HTML sanitize 홉이 추가된다. formatting.py
   sanitize_message_for_telegram을 cron/push 발송에도 적용 -- 셸 rail 포맷 누출
   (---/bold/HTML 태그)과 OPTIONS_MARKER telegram 의존 체인이 절단된다.
   (dgn822-push-sanitize, 89eb655)

6. 업데이트-있어요 노티스의 HTML raw 누출이 평문화로 해소된다. available-notice를
   HTML fold -> 평문 인라인으로 변경(dec-117 형님 확정). SessionStart 릴레이 경로
   HTML 태그 raw 누출 제거. (dgn788-notice-plaintext-canon, cf92576)

7. Ag/Warg 백업 push가 3.5주째 막혀 있던 문제가 해소된다. 프라이빗 오너 백업
   리포에서 owner-PII 카테고리(cat 2/3/4/5/9)를 face-declarable marker로 면제,
   cat 7/8(실제 시크릿/금지 추적파일)은 계속 강제. (dgn808-private-backup-exemption,
   f479364)

## Changes by Ticket

### dgn825-interim-fold-default (aac6d5f) -- 스트리밍 fold 기본화

INTERIM_MODE 미설정 도메인 에이전트의 기본값을 suppress -> fold로 변경.

### dgn825-kill-removal (cdd7201) -- /kill 커맨드 완전 제거 전파

canonical .template/bridge에 역착지. BotCommand("kill") + 미사용 문자열
CMD_DESC_KILL 제거. propagation-editor 레인: canonical .template + OSS
claude-code-telegram + 라이브 3축 전파. Skull 소비로 Ag 등 라이브 랜딩.
(DGN-581 / DGN-825 항목1)

로더 @telegram.md -> @bridge.md 교체. [[OPTIONS]] 본문 3조항(라벨+설명 필수 /
