# Release notes -- v1.19.0 (2026-07-31)

Type: FEATURE/MINOR (design-system console theme layer + onboarding color-identity gate;
no schema change; no migration required for consumers of this release).

## Summary

Two parallel design-system tracks (DGN-376 v2 S1 + DGN-650 Stage 1/3) landed together:

1. Console theme resolver (DGN-376 v2 S1 / DGN-650 Stage 1): `design_tokens.py`
   now carries three console themes -- console-dark, console-light,
   console-dark-minimal -- each verified AA 4.5:1 per surface. A new
   `resolve_design(DESIGN_THEME dark|light)` entry point maps an agent-conf
   setting to a resolved 11-slot theme plus console-bound extras (CONSOLE_EXTRAS:
   inset, wash alpha, wip pole). The design-token self-check now enforces AA on
   every registered console theme, retiring the interim card-dark/console-dark
   overlap guard.

2. Onboarding color-identity gate (DGN-650 Stage 3): the background and accent
   validators (mid-luminance dead-band, crew distinctiveness, AA reachability)
   now run live at the onboarding pick point and reject an invalid choice with a
   guided re-pick. Prior to this, the helpers existed in `design_tokens.py` but
   had no caller at the pick decision point.

Live cutover note: the console repo cutover (vendoring the resolver, wiring
`styles.py` CSS, configuring `DESIGN_THEME`) was executed same-day (2026-07-31,
DGN-650 Stage 2) independently of this canonical release. The live console
dashboard was restarted with the new theme active. The live cutover is outside
VERSION/CHANGELOG scope; it is recorded here as an operator note per close
convention.

Release approved by owner: explicit dispatcher authorization
(2026-07-31, DGN-376/DGN-650 bookkeeping dispatch).

## Added

### DGN-376 / DGN-650: console theme resolver -- design_tokens.py

`agents/.template/routines/lib/design_tokens.py`:

- Adds three console themes: console-dark (navy bg + cobalt accent, tune_accent
  derivation), console-light (navy-pale bg + cobalt #2C62B8 @4.52:1), and
  console-dark-minimal (registered, not exposed in resolve_design). All three
  pass the AA 4.5:1 constraint enforced by the updated self-check.
- Adds `CONSOLE_EXTRAS` dict: inset, wash alpha, wip pole derived from the active
  theme; surfaces that render the console consume this instead of hardcoded values.
- Adds `resolve_design(setting)`: maps DESIGN_THEME agent-conf value (dark|light,
  default dark on missing/unknown) to a registered theme object + CONSOLE_EXTRAS.
  No exception on bad input (falls back to dark).
- Retires the interim card-dark/console-dark zero-overlap guard (M5); replaces
  with per-theme AA constraint in the self-check. 133 tests green.

`agents/.template/routines/tests/test-design-tokens.py`:

- Adds test coverage for console themes (AA enforcement), resolve_design
  (dark/light/missing/unknown), and CONSOLE_EXTRAS structure.

`docs/DESIGN-SYSTEM.md`:

- Documents the console theme layer (R5): theme registration, CONSOLE_EXTRAS
  contract, resolve_design resolution order, and residual status (Stage 2
  vendoring done live; Stage 3 onboarding gate now wired).

### DGN-650: onboarding color-identity gate -- dogany-user-onboarding SKILL.md

`skills/dogany-user-onboarding/SKILL.md`:

- Color-identity pick point now calls `validate_background`, `accent_distinct`,
  and `accent_conflicts_with_crew` at selection time. Invalid choice triggers
  a guided re-pick with the constraint violation named (mid-luminance reject,
  crew-distinctiveness gap, AA fail). Prior state: helpers present, no caller.
