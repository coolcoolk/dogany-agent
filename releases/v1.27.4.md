## Purpose

세 건의 마무리 패치 번들 (patch): 브릿지 버튼 라벨 폭 재보정(DGN-779), 카운트다운
타이밍·UI 개선(DGN-780/780b), 업데이트 안내문 정리(DGN-784). 새 기능 앵커 없이
직전 v1.27.3 재벤더 번들에 얹힌 정합·다듬기 성격.

## Changes

### DGN-779 -- 옵션 버튼 라벨 폭 계수 재보정

`agents/.template/bridge/options.py`: `_label_width` / `_shorten_button_label`의
가중 폭 계산에 공백 전용 분기 추가 (`isspace()` -> 0.4; 기존 1.0은 온디바이스
실측 ~0.25 대비 2.7배 과대계상). `_BUTTON_LABEL_MAX_WIDTH` 30.0 -> 31.0 (온디바이스
1줄 경계 ~31.5, ellipsis 글리프 1.0 예약). iPhone 13 mini 실측 재보정(2026-08-07).
테스트 `tests/test_dgn704_label_shorten.py`: budget 어서션 30.0 -> 31.0, exact-width
픽스처 보정(29.4), 공백 가중 케이스 3건 추가.

### DGN-780 / DGN-780b -- 카운트다운 타이밍 스냅 + UI 재디자인 + 자유형 확장

`agents/.template/bridge/countdown.py`, `config.py`, `i18n/en.py`, `i18n/ko.py`,
`tests/test_countdown.py`:

- DGN-780: 편집 루프가 고정 캐던스 nap 대신 마감 앵커 경계 스냅(`_next_boundary`)으로
  전환 -- editMessageText 지연이 표시 드리프트로 누적되지 않는다. 바를 DRAIN(채워진 =
  잔여) 형태로 재디자인, hourglass/check 아이콘 + 검증된 글리프 allowlist(dot 기본 /
  block-line / square) 뒤에 새 config 노브 `COUNTDOWN_GLYPH_SET` 추가.
- DGN-780b: `start_countdown` / `Countdown` / `render_countdown`에 선택적
  `icon`/`done_icon`/`glyph` 파라미터 추가, 단일 우선순위 리졸버(call > config >
  default) + 마크다운 위험/안전하지 않은 값에 대한 silent safe fallback. i18n 템플릿에
  `{icon}`/`{done_icon}` 플레이스홀더 추가. 컨트롤 파일 스키마에 선택적
  `icon`/`done_icon`/`glyph` 필드 추가(glyph = preset 이름 또는 [filled, empty] 쌍).
  파라미터 생략 시 기존 기본 모양 재현(하위 호환).

### DGN-784 -- 업데이트 안내문 CHANGELOG fallback 제거

`agents/.template/routines/version-check.py`, `self-update.sh`: 업데이트 완료 안내에서
user-summary가 비었을 때 `changelog_section()` / `_release_notes_local()` /
`_release_notes_remote()`로 대체하던 fallback을 3개 호출부 전량 제거. CHANGELOG는
영어/개발자용(DGN-210)이며 raw 마크다운, 백틱, 내부 파일·함수명(`bridge/countdown.py`,
`start_countdown`, `EditRateGuard` 등)을 포함 -- user-facing 출력에 노출되어서는 안 된다.
user-summary가 없으면 fold body를 비운다(안전한 침묵 > 개발용 원문 노출).
`releases/vX.md`의 `<!-- user-summary -->` 계약(DGN-699)은 변경 없음. 신규 테스트
`tests/test-dgn784-update-note-sanitize.py`: user-summary 출력에 ### 헤더/백틱/내부경로
부재를 어서트하는 7 케이스.
