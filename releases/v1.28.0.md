## 목적 (purpose)

이번 마이너의 앵커는 base-kit 도입 -- 새 메인 에이전트가 온보딩에서 자기 역할(킷)을
고를 수 있게 하는 킷 선택 머신러리다. 인접 라이더로 업데이트 완료 통지의 정보 구조(IA)
개편을 함께 싣는다.

## 핵심 변경

- base-kit 킷 선택 배선 (DGN-466 / DGN-783 BK-1): 새 메인 에이전트가 온보딩 마지막에
  역할을 고른다 -- "생활 전반 관리"를 고르면 라이프킷(식사·운동·약속·관계)이 설치되고,
  "특정 업무 집중"이면 킷 없이 시작한다. 내부적으로 `KIT=` 트라이스테이트(pending ->
  lifekit|none) + 클래스 enum(main|domain)으로 게이팅하며, 티어 언어는 제거했다(DGN-590).
  잘못된 프리셋 값은 화이트리스트로 걸러 pending으로 폴백한다.
- 업데이트 통지 IA 개편 (DGN-785): 완료 통지 접기 블록을 [업데이트 요약] / [업데이트 상세] /
  [새로 해볼 수 있는 것] 3섹션으로 재구성하고, 티켓번호 등 개발용 표기가 사용자 화면에
  노출되지 않도록 자동 제거한다. 섹션이 비면 조용히 생략한다.

## 안내 (notes)

- minor 릴리스: 앵커 목적(base-kit) 1개 + 통지 IA 라이더. base-kit의 후속 단계(BK-2
  DB 통합 등)는 별도 마일스톤(1.29+).
- 릴리스노트 `<!-- user-summary -->` 계약(DGN-699) 준수: 이번 릴리스가 신규 3섹션 통지의
  첫 데뷔라 ko/en + try 키를 채워 통지가 빈 화면으로 뜨지 않게 했다.
- 온보딩 킷 선택 안내 문구는 오너 확인 카피(형님 승인, i18n `kit.offer` ko/en)로 배선됐다.
- 기존 라이브 인스턴스의 `KIT=` 파생 마이그레이션(step-4)은 이 릴리스 미포함 -- 별도 후속.
