## 목적 (purpose)

앵커: Why-tethering 원칙 정본 편입 (DGN-900).
RULES Principles에 means-end inversion 방지 룰 추가 -- 결정 중요 액션에서 2+ Why 후보
생존 시 STOP + 전체 후보 제시(one-collapsed-guess / bare-ask 금지); Why 확정 후 최적 How
재도출 + better-How 존재 시 제안; micro/safe/reversible 액션 예외(just act).
정본 기준 편입으로 self-update를 통해 전체 라이브 인스턴스에 전파된다.

Riders:
- bridge authsync 커맨드 (DGN-759): /authsync 슬래시 커맨드 -- 재로그인 후 credential
  재시동 없이 브릿지에 동기화.
- compat-lint bak-residue 강화 (DGN-868): C4b bak-잔재 fixture 수정(거짓음성 소거) +
  test-secret-sweep.sh 회귀 하네스 신설.
- /btw 슬래시 커맨드 (DGN-902): 세션-포크 격리로 aside 메모 분기 -- 본 대화 맥락 오염 없음.
- release-closer step 7 (B1): 릴리스 마감 서브에이전트가 rider 열린 티켓 읽기-전용 스캔 +
  shipped-but-open 후보 마감 보고서에 기록(3-place edit 범위 밖 쓰기 없음).

- 왜: (1) means-end inversion 패턴(How/What을 목표로 굳히는 실수)이 에이전트 판단에서
  반복적으로 발생하는 구조적 취약점으로 식별됐다. "콘텍스트만 있으면 Why를 추론할 수 있다"는
  가정이 실제 복수 후보 생존 상황에서 오판으로 이어졌다. 정본 Principles 층에 편입해 모든
  인스턴스에 구조적으로 강제한다.
  (2) credential 재로그인마다 브릿지 전체 재시동이 필요해 불필요한 다운타임이 발생했다 --
  authsync 커맨드로 재시동 없이 동기화.
  (3) compat-lint C4b bak-잔재 검사의 fixture 누락으로 실제 bak 잔재가 있어도 검사가 발화하지
  않는 거짓음성이 확인됐다 -- fixture 수정으로 봉합.

## Highlights

1. Why-tethering 원칙이 RULES Principles에 편입된다. 결정 중요 액션에서 2+ Why 후보가
   살아남으면 에이전트는 전부 제시하고 멈춘다 -- 임의 축약이나 bare "왜?"로 묻는
   행동이 원천 차단된다. Why가 확정되면 최적 How를 재도출하고 더 나은 방법이 존재하면
   제안한다. micro/safe/reversible 액션은 예외(그냥 실행). self-update로 전체 인스턴스에
   전파된다. (DGN-900)

2. /authsync 슬래시 커맨드가 추가된다. 재로그인 후 Telegram credential을 브릿지
   재시동 없이 실시간으로 동기화한다. credential 로테이션으로 인한 불필요한 다운타임
   제거. (DGN-759)

3. compat-lint C4b bak-잔재 검사의 거짓음성이 소거된다. fixture 수정으로 C4b가 실제로
   발화하게 되며, test-secret-sweep.sh 회귀 하네스가 신설돼 secret-sweep 경로 재발을
   방지한다. 유저 가시 변화 없음. (DGN-868)

4. /btw 슬래시 커맨드가 추가된다. 본 대화 맥락을 오염시키지 않고 aside 메모·생각을
   세션-포크 격리로 분기할 수 있다. (DGN-902)

5. release-closer 서브에이전트에 step 7이 추가된다. 릴리스 마감 시 rider 티켓 중 열린
   항목을 읽기-전용으로 스캔하고 shipped-but-open 후보를 마감 보고서에 기록한다.
   티켓 상태 변경은 하지 않는다(one-writer 규칙 유지). (B1)

## Changes by Ticket

### DGN-900 -- Why-tethering estate rule (anchor)

**RULES Principles 편입**
RULES Principles에 Why-tethering 룰 블록 추가.
- 결정 중요(decision-bearing / irreversible / systemic / external-destructive) 액션에서
  2+ candidate Why가 생존 시: STOP, 전체 후보 제시(초대 -- closed A/B 아님). 단일 후보로
  임의 축약 금지; bare "왜?" 질문 금지; 컨텍스트에서 후보 도출.
- Why 확정 후: 최적 How 재도출, 더 나은 How가 존재하면 제안.
- micro/safe/reversible 액션: 예외, 그냥 실행.
- 상세: sot/COGNITION-DOCTRINE.md Why-tethering (cross-ref).

**전파 경로**
RULES.md는 정본 기준(agents/.template/RULES.md symlink + minted instance real copy).
self-update 경로에서 라이브 인스턴스로 전파된다.

### DGN-759 -- bridge authsync 커맨드

**/authsync 슬래시 커맨드**
bridge/에 authsync 핸들러 추가. 재로그인 완료 후 `/authsync`를 발행하면 브릿지가
새 credential을 로드하고 연결을 재설정한다. 브릿지 프로세스 재시동 불필요.
기존: credential 교체마다 브릿지 전체 재시동 -> 다운타임 발생.
수정: authsync 핸들러가 credential 재로드 + 연결 재설정을 논블로킹으로 처리.

### DGN-868 -- compat-lint bak-residue 강화

**C4b fixture 수정 (거짓음성 소거)**
scripts/tests/test-compat-lint.sh T11 bak-잔재 fixture에 payload/ 디렉터리가 누락돼
C4b 검사 분기에 진입하지 않아 항상 PASS하던 거짓음성 수정.
수정: fixture에 payload/ 구조 추가 -> C4b가 실제 bak 잔재를 탐지하고 FAIL 반환.

**test-secret-sweep.sh 신설**
scripts/tests/test-secret-sweep.sh 회귀 하네스 추가.
secret-sweep 경로의 탐지/비탐지 케이스를 자동 검증 -- 향후 sweep 경로 수정 시
회귀 차단.

유저 가시 변화 없음.

### DGN-902 -- /btw slash command

**/btw 슬래시 커맨드 (세션-포크 격리)**
`/btw <내용>` 커맨드로 aside 메모·생각을 별도 세션 포크로 분기.
포크는 본 대화 컨텍스트와 격리되어 메인 스레드를 오염시키지 않는다.
포크별 격리 적용.

### B1 -- release-closer step 7

**rider 열린 티켓 읽기-전용 스캔**
release-closer 서브에이전트 마감 프로세스에 step 7 추가.
릴리스 rider로 지정된 DGN 티켓 중 상태가 done/resolved/closed가 아닌 항목을
읽기-전용으로 스캔하고 마감 보고서에 "shipped-but-open" 후보로 기록.
티켓 상태 변경 없음(one-writer 규칙; Done 판정은 Metal 메인 세션 전용).
보고서 출력만, 3-place edit 범위 밖 쓰기 없음.

## Known Notes

   맡겨져 있다. 과도한 STOP이 발생하면 micro 판정 기준을 sot/COGNITION-DOCTRINE.md에서

   예정).
