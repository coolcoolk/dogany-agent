## 목적 (purpose)

앵커: in-place drilldown capture 프리미티브(idrill) + 출력규율 정합 + conf 파서 통일.

브릿지에 범용 단계형 캡처 프리미티브를 추가한다: 콜백 버튼 탭이 같은 메시지를
다음 스텝 키보드로 in-place 교체해 가다가, 마지막 탭에서 arm 파일에 선언된
argv를 실행(one-shot 소비, 쉘 미경유 contract v2)하고 메시지를 확인 문구로
교체한다. 모델 턴 0, 새 메시지 0. 브릿지는 도메인을 모른다 -- 팩(콘텐츠)이
arm 파일만 쓰면 어떤 단계형 입력에도 쓸 수 있는 프로세스-경계 프리미티브다
(Metal 잔여 스코프: cross-kit primitive). 첫 적용 사례(first application)는
운동 세트 기록. 라이더로 결정-응답 프레임 스킬/RULES 출력규율 정합(DGN-921)과
단일 conf 파서 통일(DGN-916)을 동반한다.

Anchor: DGN-918
Riders: DGN-921, DGN-916

## Highlights

1. in-place drilldown capture (DGN-918). 버튼 탭 -> 같은 메시지가 다음 스텝
   키보드로 스왑 -> 마지막 탭이 arm 파일(one-shot, traversal 가드) 소비 +
   선언 argv 실행(위치 기반 값 치환, 쉘 미경유) + 확인 문구 in-place 렌더.
   만료/중복 탭은 fail-soft 안내. 도메인 중립(브릿지에 도메인 필드 지식 없음);
   첫 적용 = 운동 세트 기록. i18n(en/ko) 범용 문자열 + 전용 테스트 스위트(71) 동반.

2. 결정-응답 프레임 정합 (DGN-921). dogany-decision-reply-frame SKILL의
   추천 마커 규칙을 "본문 라인 전용, 버튼 라벨 금지"로 교정(bridge.md 버튼
   라벨 규약 정렬), 한국어 트리거 추가, RULES.md 크로스레퍼런스 정렬.

3. 단일 conf 파서 (DGN-916). routines/lib/conf_reader.py 신설 -- agent.conf
   따옴표/공백 정규화를 한 곳으로 통일. onboarding-check / output-gate-stop /
   session-recap / status-footer / usage-gate 5개 루틴이 채택(guarded import,
   fail-open 계약 유지). 구 canonical 브랜치 dgn916-conf-parser(revert 계보)는
   본 reland로 대체 -- fold 금지.

## Changes by Ticket

### DGN-918 -- idrill in-place drilldown capture primitive (anchor)

**변경 전:** 단계형 입력(값 두 개를 순서대로 받는 캡처)은 타이핑(자연어->모델 턴)
경로뿐 -- 입력 부담 + 모델 턴 소비.
**변경 후:** 메시지에 붙은 버튼 탭 -> 같은 메시지가 다음 스텝 키보드로 스왑 ->
마지막 탭이 선언된 명령을 실행하고 같은 메시지가 확인 문구로 바뀐다.
모델 턴 0, 새 메시지 0.

계약(contract v2): 팩이 arm 파일(`files/program/.idrill-arm/<arm_id>.json`)에
선언한 argv(`cmd` / `cmd_skip2`)를 브릿지가 위치 기반 값 치환 후 argv exec
(쉘 미경유). arm 파일은 fire 시 소비(one-shot) -- 중복 탭은 만료 안내. arm_id는
traversal 가드(정규식) 통과 필수. 실패는 전부 fail-soft(만료/명령 부재/비정상
종료). 브릿지는 도메인 필드를 모른다(도메인 중립) -- 첫 적용 사례는 운동 세트
기록이며, 프리미티브 자체는 어떤 2단계 캡처에도 재사용 가능.
경계 = 파일/CLI/exit-code; contract_version 표면 신설 없음.

### DGN-921 -- decision-reply-frame / RULES output-discipline reconcile (rider)

S1: 추천 마커는 본문 리스트 라인 전용, 버튼 라벨에 금지(bridge.md 버튼 라벨
규약 정렬) -- canonical + template SKILL 동시 수정.
S2: 스킬 description에 한국어 트리거 추가.
S3: RULES.md 크로스레퍼런스를 영어 템플릿 섹션명('Response skeleton')으로 정렬.

### DGN-916 -- single conf parser reland (rider)

`routines/lib/conf_reader.py` 신설: `conf_get(key, conf_path)` 단일 진입점,
따옴표/공백 정규화 일원화. 채택 루틴 5종은 guarded import로 lib 부재 시에도
fail-open 계약 유지. 전용 테스트(test-dgn916-conf-reader.py) 동반.
carry 시 golden divergence 보존: usage-gate.py의 canonical 고유 DGN-835 relief
층 유지(3-way 병합), session-recap.py의 템플릿 플레이스홀더 유지.
