## Purpose

통지/fold 마무리 안정화 번들 (UX 앵커) + 테스트/훅 위생 라이더.

앵커 목적(DGN-764/766/777): 완료 통지 레이아웃과 fold 마무리 로직의 세 가지 결함을 한
번에 묶어 수정한다. 완료 통지가 두 개의 말풍선으로 쪼개지는 문제(DGN-766), fold 라벨의
잉여 말줄임표(DGN-764), 그리고 최종 답변 문단이 fold 안에 갇혀 사라지던 결함(DGN-777).
라이더(DGN-716/727/760): 테스트 단언 정합, pre-push 훅 경로 교정, conftest hermetic화.

## Changes

### DGN-764 -- 업데이트 통지 fold 라벨 꼬리 말줄임표 제거

`agents/.template/routines/self-update.sh` fold 라벨 4곳에서 꼬리 "…" / "..." 제거:

- ko: "이번 업데이트 요약 …" -> "이번 업데이트 요약"
- ko: "자세한 변경 내용 …" -> "자세한 변경 내용"
- en: "This update at a glance ..." -> "This update at a glance"
- en: "Detailed changes ..." -> "Detailed changes"

Telegram expandable blockquote 자체가 펼침 어포던스를 제공하므로 라벨의 리터럴 말줄임표는
잉여이자 지저분했다(형님 지적 2026-08-06). 보존: 2500자 초과 절삭 마커("…(이하 생략 …)")는
기능성 표지이므로 유지.

### DGN-766 -- 업데이트 완료 통지 단일 expandable 블록으로 통합

`agents/.template/routines/self-update.sh` 방출부: `_notes`용 blockquote +
`_detail`용 blockquote 두 개를 **단일 `<blockquote expandable>`** 로 통합.

- 요약 섹션(`_fold` + notes) 먼저, 빈 줄 후 자세한 변경 섹션(`_detail_label` + detail).
- 어느 쪽이 비어도 남은 쪽만 단일 블록으로(fail-open). 둘 다 없으면 블록 없음(기존 유지).
- 접힌 미리보기 = "이번 업데이트 요약" 첫 줄; 펼치면 요약+자세한 변경 한 블록.

DGN-718이 update-available 통지에 단일 fold를 적용한 원칙과 동일하다. DGN-764와
동일 브랜치(인접 표면 번들).

### DGN-777 -- fold 최종답 불변 원칙 (final-sacred)

`agents/.template/bridge/sdk_bridge.py` finalize 경로의 dedup 방향 교정.

**결함**: grown fold가 있을 때 최종 답변 문단이 진행 기록(interim fold)과 부분 겹치면
`_dedup_final_against_interim`이 해당 문단을 최종답에서 제거 -> 필요한 말이 최종답에서
사라지고 접힌 fold 안에만 남음(펼쳐야 보임). 오너 지적 2026-08-07: 최종답에 있어야 할 내용이 통째로 누락돼 보인다는 것.

**수정 원칙 (final-sacred)**:
- 최종답(answer)은 신성불가침: finalize에서 최종답 문단을 절대 제거하지 않는다.
- 겹침 제거 방향 반전: 겹치는 문단은 fold(진행 기록) 쪽에서 차집합으로 제거한다.
- 최종답이 fold를 전부 재현(`_final_fully_in_interim` True): 기존대로 `fold_delete`(fold
  통째 삭제, 최종답 전체 유지) -- 이미 옳음, 유지.
- 부분 겹침(else): 최종답 전체 유지. fold 렌더를 (fold - 최종답겹침문단) 차집합으로 다듬어
  화면 중복만 제거. 다듬은 뒤 fold가 비면 -> fold_delete로 귀결.
- `_dedup_final_against_interim`(최종답에서 빼는 함수)는 finalize 경로에서 제거/대체.

수정 site: grown-fold 경로 + compose-fallback 경로. 신규 헬퍼: fold_texts를 최종답 문단
대비 차집합으로 다듬는 순수함수. 문단 분할 규약은 기존 `_norm`/`re.split(r"\n\s*\n")` 유지.

테스트(`test_dgn699_growing_fold.py` 확장): (a) 부분겹침 -> 최종답 전체 보존 + fold에서
겹침문단 제거, (b) 전체겹침 -> fold_delete + 최종답 전체, (c) 겹침없음 -> 양쪽 불변,
(d) 다듬은 fold 공백화 -> fold_delete 귀결.

### DGN-716 -- smoke-gate selftest S1 단언 현행 push 문구에 정합 (테스트 전용)

`tests/dgn712_smoke_gate_selftest.sh` S1 단언을 현행 abort-warning push 문구
("업데이트 잠시 보류")에 맞게 갱신. v1.24.1 출시 이후 실제 push 문구가 바뀌면서 단언이
stale해져 S1이 FAIL하던 것을 수정. 동작 변경 없음, 테스트 전용 수정.

### DGN-727 -- pre-push secret-sweep 폴백 경로 repo-상대 교정

`scripts/publish.sh` pre-push 훅 내 secret-sweep 스크립트 폴백 경로를 절대경로
하드코딩(`~/dogany/Metal/scripts/secret-sweep.sh`, DGN-036 이전 잔재)에서
repo-상대 경로로 교정. 워크스페이스 재이전 시 경로 부재로 fail-closed 차단되는 문제
방지. 개발 위생 수정, 기능 변경 없음.

### DGN-760 -- conftest hermetic PROJECT_ROOT 강제 (테스트 위생)

`agents/.template/bridge/tests/conftest.py` PROJECT_ROOT 설정 방식을 `setdefault`
(셸 환경 우선)에서 테스트 전용 hermetic 고정으로 전환. 이전에는 실행 셸에
`PROJECT_ROOT`(라이브 메탈 인스턴스 경로)와 `INTERIM_MODE=fold`가 있으면 라이브
`.telegram_bot/.env`를 로드해 `test_dgn426` 4건 + `test_dgn429` 1건 어서션이
환경에 따라 뒤집혔음(누수 셸: 5 failed, clean 셸: 25 passed). 수정 후 어서션은
셸 환경과 무관하게 결정론적으로 실행됨.
