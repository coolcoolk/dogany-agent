Stable maintenance release. Claude Code releases that carry a new model
install at the dawn run without the 24h wait, and model names follow what the
CLI actually runs. A failed /update records its cause and the agent
investigates it; stalled installs repair their update machinery when the
install command is run again. /update applies framework, kits, then packs.
Smaller fixes to notices, /usage, language guidance and background jobs.
See CHANGELOG.md.
