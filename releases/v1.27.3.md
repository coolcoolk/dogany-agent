## Purpose

OSS 브릿지 증분(ce3b597..8ace92b) 재벤더 앵커 번들.

앵커(DGN-594): 비핀 transient 카운트다운 프리미티브(start_countdown, 10초 캐던스
in-place 편집, 공유 EditRateGuard 추출). 워그 운동 휴식 타이머의 실시간 카운트다운이
이 프리미티브를 사용하며, 사용자 표면에서는 봇이 남은 시간을 한 메시지에서 실시간
갱신하는 형태로 드러난다.

라이더: DGN-706/706b(재시작 후 resume-intent 자동 표시 + 업데이트 후 버전 자동 통지),
DGN-775(마크다운 sanitize 백스톱), DGN-704c(옵션 라벨 fix), DGN-719 phase-1(출력
계약 정합화). 재벤더 범위 내 OSS 증분만 착지; 캐노니컬 전용 서브시스템은 전량 보존.

## Changes

### DGN-594 -- 비핀 transient 카운트다운 프리미티브 + 공유 EditRateGuard

신규 파일: `agents/.template/bridge/countdown.py`, `agents/.template/bridge/edit_guard.py`,
`agents/.template/bridge/tests/test_countdown.py`, `agents/.template/bridge/tests/test_edit_guard.py`.

`start_countdown(bot, chat_id, msg_id, seconds, body_fn, ...)`: 주어진 메시지 ID를 10초
캐던스로 in-place 편집해 카운트다운을 표시하는 asyncio 태스크. 새 메시지를 쏟아내지
않고 동일 메시지 하나에서 남은 시간이 갱신된다. `body_fn`은 잔여 초를 인자로 받아
편집할 텍스트를 생성한다.

`EditRateGuard(edit_guard.py)`: Telegram 편집 속도 제한을 관리하는 공유 프리미티브.
`countdown.py`와 브릿지의 fold 편집 경로가 동일 인스턴스를 공유해 편집 충돌 없이
협업한다.

`bot.py` 연동: CountdownDriver import + 태스크 create + finally cancel 배선.

`messages.py` / `i18n/en.py` / `i18n/ko.py`: `countdown_body` / `countdown_done` 메시지 키 추가.

### DGN-706 / DGN-706b -- 재시작 후 resume-intent 자동 표시 + 업데이트 후 버전 자동 통지

`agents/.template/bridge/self_restart.sh` step-4 브랜치 추가:

- DGN-706(resume-intent): 재시작 완료 후 `--resume-intent "<작업 + 다음 액션>"` 인자가
  있으면 사용자에게 자동으로 이어가던 작업을 표시. 재시작 전 Metal이 `--resume-intent`를
  패스하지 않으면 "이어가는 작업 없음" 선언으로 처리된다.
- DGN-706b(version-update auto-notice): 자가 업데이트(self-update) 완료 후 버전 변경을
  자동 통지. `VER_MARKER` + `html_esc` 헬퍼로 구버전->신버전 표시. 캐노니컬 전용 서브시스템
  (DGN-712 smoke gate, `__AGENT_NAME__`/`__AGENT_PREFIX__` 플레이스홀더,
  DGN-687/233 한국어 페르소나 통지)은 전량 보존.

### DGN-775 -- 텔레그램 마크다운 sanitize 백스톱

`agents/.template/bridge/formatting.py` 및 `agents/.template/bridge/options.py`:
브릿지 출력 파이프라인에 sanitize 백스톱 추가. 헤더(`#`), 표(`|col|`), 옵션 라벨의
마크다운 raw 노출을 방지한다. 에이전트가 규율을 어긴 경우에도 Telegram 사용자 화면에
raw 기호가 그대로 노출되지 않는다.

### DGN-704c -- 옵션 버튼 번호전용 라벨 fix

`agents/.template/bridge/options.py`: `[[OPTIONS]]` 버튼 라벨이 파싱 엣지케이스에서
번호만 단독으로 렌더링되던 문제 수정. 번호+레이블 조합이 정상적으로 버튼에 표시된다.

### DGN-719 phase-1 -- 브릿지 출력 계약 정합화

`agents/.template/bridge/formatting.py`, `agents/.template/bridge/options.py`:
코어 의미 계층과 렌더 계층 출력 계약의 정합화. 이전에 미푸시 상태였던 pin 계보
(ce3b597 이전 OSS 정합 포함) 착지. `agents/.template/bridge/tests/test_dgn704_label_shorten.py`
clean-reflect. `dashboard.py` clean-reflect(byte-identical to pin ce3b597).
